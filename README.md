Türk İşletme Site Kurucu

Türkiye'deki küçük işletmeler için yapay zekâ destekli internet sitesi oluşturma platformu.

🎯 Projenin Amacı

Teknik bilgiye ihtiyaç duymadan, birkaç basit adımla profesyonel bir internet sitesi oluşturmayı kolaylaştırmak.

✨ İlk Sürüm Özellikleri

- Türkçe kullanıcı arayüzü
- İşletme bilgileriyle site oluşturma formu
- Hazır internet sitesi şablonları
- Mobil uyumlu tasarım
- WhatsApp iletişim düğmesi
- Site önizleme
- Cloudflare Pages üzerinden yayınlama

🏪 Hedef İşletmeler

- Emlak ofisleri
- Restoranlar ve kafeler
- Kuaförler ve güzellik salonları
- Küçük işletmeler
- Eğitim kurumları
- Serbest çalışanlar

🛠️ Teknoloji

- HTML
- CSS
- JavaScript
- GitHub
- Cloudflare Pages

🚀 Geliştirme Planı

1. Temel ana sayfayı hazırlamak
2. İşletme bilgileri formunu oluşturmak
3. Hazır site şablonlarını eklemek
4. Mobil görünümü iyileştirmek
5. Cloudflare Pages üzerinden yayınlamak
6. İlerleyen aşamada yapay zekâ özelliklerini eklemek
